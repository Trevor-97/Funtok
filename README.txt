FUNTOK — TikTok-style short-video web app starter

WHAT'S INCLUDED
- Vertical, swipe/scroll video feed
- Mobile-first layout with desktop preview
- Upload a video from your device (local browser preview)
- Like buttons, follow buttons, comments and share-link action
- Search the sample feed
- Installable PWA shell (when hosted over HTTPS)

RUN IT
1. Extract FunTok.zip.
2. Open the FunTok folder.
3. Double-click index.html to preview in a modern browser.
4. For install/offline features, host it on HTTPS (for example GitHub Pages).

IMPORTANT
This is a front-end prototype. Uploaded videos are previewed locally in your browser; they are NOT uploaded to a shared server and other users cannot see them. Accounts, secure login, cloud video storage, real comments/likes, moderation, and a recommendation system require a backend. Do not publish private videos or personal information in this demo.

PUBLISHING WITH GITHUB PAGES
1. Create a GitHub repository named FunTok.
2. Upload all files from this folder to the repository's root.
3. Open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for the published URL shown on the Pages screen.

NEXT DEVELOPMENT STEP
